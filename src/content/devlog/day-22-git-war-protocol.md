Главная проблема — постоянная война с Git. Пошла уже 9-я версия протокола. Агенты требуют все более строгих правил:

- Стадия 1: Косячат агенты.
- Стадия 2: Дали протокол и скиллы.
- Стадия 3: Агенты косячат, права отобрали, оверлорды пушат.
- Стадия 5: Скилл требует соблюдать протокол.

Забрал у ботов ключи, сделал скилл `git-publish`. Теперь только Pull Request, никакого мусора в контексте.
