# AuroraCore - Agent Instructions

## What is this
AuroraCore is an R&D project building an intent-first operating system
for AI agents. Current agents operate through human interfaces (GUI, CLI,
APIs designed for humans). AuroraCore builds a native environment where
agents can efficiently execute tasks, communicate with each other, and
manage machine/network resources.
